# Weather Forecast App

A responsive weather app built with HTML, CSS, and vanilla JavaScript. Search any city to see current conditions and a 5-day forecast.

**Live demo:** https://weather-forecast-app-chi-peach.vercel.app/

## Features
- Search by city, with clear error messages
- Current temperature, conditions, humidity, wind, and "feels like"
- 5-day forecast with temperature range bars
- °C/°F toggle
- "Use my location" button
- Recent searches saved in localStorage
- Page colours change with the weather and switch to a dark theme at night

## Built with
HTML, CSS, JavaScript, and the [Open-Meteo API](https://open-meteo.com/) (no API key needed)

## Run locally
Download the files and open `index.html` in your browser.
